### 📂 저장소 구성 (Repository Structure)

이 저장소는 다음과 같은 구조로 구성됩니다.

| 폴더/파일 | 설명 |
| :--- | :--- |
| `01_Python_Basic/` | 파이썬 기본 문법 및 자료 구조 학습 코드 (`if`, `for`, 함수, 리스트 등) |
| `02_IOT_Modules/` | IoT 환경에서 자주 사용되는 파이썬 모듈 및 라이브러리 실습 코드 (e.g., `requests`, `pyserial`, 센서 제어 관련 라이브러리) |
| `03_Project_Codes/` | 수업 중 진행하는 미니 프로젝트 또는 최종 프로젝트 관련 코드 및 보고서 |
| `04_Notes/` | 수업 필기, 개념 정리, 문제 풀이 등의 문서 자료 (Markdown 또는 PDF) |

| `requirements.txt` | 프로젝트에 필요한 파이썬 패키지 목록 |

### 💡 학습 목표 (Learning Objectives)

1.  **파이썬 기본기 숙달:** IoT 장치 제어 및 데이터 처리에 필요한 파이썬 기본 문법 및 객체 지향 개념 이해.
2.  **IoT 환경 이해:** 센서, 액추에이터, 통신 프로토콜 등을 파이썬으로 제어하고 데이터를 수집/분석하는 능력 함양.
3.  **실무 적용 능력:** 배운 내용을 바탕으로 실제 IoT 시스템을 설계하고 구현하는 미니 프로젝트 경험.

### 💻 실행 환경 설정 (Setup)

이 저장소의 코드를 실행하기 위해서는 **Python 3.x** 버전이 필요합니다.

1.  **파이썬 설치:** 공식 웹사이트에서 파이썬을 다운로드하여 설치합니다.
2.  **저장소 복제 (Clone):**
    ```bash
    git clone [저장소 URL]
    cd [저장소 이름]
    ```
3.  **필요한 라이브러리 설치:** `requirements.txt`에 명시된 패키지들을 설치합니다.
    ```bash
    pip install -r requirements.txt
    ```
